## 🚀 Como Publicar no GitHub Pages

1. Crie um repositório no seu GitHub (ex: `catalogo-renault` ou `<seu-usuario>.github.io`).
2. Faça o commit e push de todos os arquivos desta pasta para a branch principal (`main`).
3. No GitHub, vá em **Settings** > **Pages**.
4. Em **Branch**, selecione `main` e a pasta `/ (root)`.
5. Clique em **Save**. Em menos de 1 minuto, seu site estará no ar com link público!
